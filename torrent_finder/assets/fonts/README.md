# The terminal font

`PxPlus_IBM_VGA_8x16.ttf` is the IBM VGA 8x16 font from *The Ultimate Oldschool
PC Font Pack* v2.2 (2020-11-21) by VileR, <https://int10h.org/oldschool-pc-fonts/>,
included unmodified. It is licensed under the Creative Commons
Attribution-ShareAlike 4.0 International licence, whose text is in `LICENSE.TXT`
(<https://creativecommons.org/licenses/by-sa/4.0/>).

The Windows Terminal profile (Settings › Appearance › Windows Terminal) installs
it for the current user and uses it in the profile.
