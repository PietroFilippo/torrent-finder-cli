# The terminal fonts

The Athanor design's fonts are from *The Ultimate Oldschool PC Font Pack* v2.2
(2020-11-21) by VileR, <https://int10h.org/oldschool-pc-fonts/>, included
unmodified:

| File | Font | Cell |
| --- | --- | --- |
| `PxPlus_IBM_VGA_8x16.ttf` | IBM VGA 8x16 | 8x16 |
| `PxPlus_IBM_VGA_9x16.ttf` | IBM VGA 9x16 | 9x16 |
| `PxPlus_ToshibaTxL1_8x16.ttf` | Toshiba TxL1 8x16 | 8x16 |
| `PxPlus_AST_PremiumExec.ttf` | AST Premium Exec | 8x19 |
| `PxPlus_IBM_XGA-AI_12x20.ttf` | IBM XGA-AI 12x20 | 12x20 |

They are licensed under the Creative Commons Attribution-ShareAlike 4.0
International licence, whose text is in `LICENSE.TXT`
(<https://creativecommons.org/licenses/by-sa/4.0/>).

The Windows Terminal profile (Settings › Appearance › Windows Terminal) installs
them for the current user, and Settings › Appearance › Font picks the one it
uses. The Simple design's fonts (Cascadia Mono and Code, Consolas, Lucida
Console) come with Windows and Windows Terminal; none is bundled.
