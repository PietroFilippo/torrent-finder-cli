# Torrent Finder CLI v0.6.0

This release adds strict Brazilian Portuguese audio filtering, better result
refinement, and fixes for missing logins, short anime searches, credential
storage, compact terminals, and Windows updates.

## New features

- **PT-BR audio:** enable **Dublado (PT-BR)** in Movies & Series with **Ctrl+F**.
  Searches include regional release terms and additional sources. Results must
  contain explicit Brazilian audio tags; generic Portuguese, PT-PT, subtitle-only
  tags, and “Dual Audio” alone do not qualify. Track contents are not inspected.
- **Refine results with f:** match words, an exact media title ignoring common
  release tags, or the full filename. Sort fetched results by newest upload,
  seeders, name, size, or original order. Unknown dates sort last, and sorting
  keeps selections attached to the correct downloads.
- **Compact menus:** short windows use tighter padding and a one-line banner.
  Position indicators replace “more above/below” rows. Action menus scroll too;
  PgUp/PgDn and Home/End make longer menus easier to navigate.

## Fixes

- **Missing logins:** Madokami and RuTracker report missing or rejected
  credentials instead of silently returning an empty search. Changing or
  clearing credentials refreshes cached sessions.
- **Short anime titles:** searches such as **Saki** no longer rely only on
  Nyaa's recent RSS matches. One- or two-word queries with no exact-title result
  get one additional catalog lookup. Exact titles rank first; original RSS
  results remain available. This improves discovery without guaranteeing every
  older release will be found.
- **Game search noise:** FitGirl and Online-Fix require query words in the
  parsed game title, avoiding matches from post bodies or neighboring links.
- **Credential storage:** Windows credentials now live at
  `%USERPROFILE%\.torrent-finder-cli\subtitle_credentials.json`. Legacy copies
  are recovered when the new file is absent, preserving the originals and
  keeping each integration's fields together. Corrupt or unreadable files block
  saving instead of letting a partial edit overwrite other credentials.
- **Metadata guidance:** the file-list prompt explains that reported seed
  counts may be stale and fetching metadata can time out when no suitable peers
  are reachable.
- **Cancellation:** Ctrl+C consistently backs out of active menus and cancels
  searches or metadata waits; the provider menu keeps its double-press quit guard.
- **Windows package updates:** pip/pipx upgrades run in a hidden helper after
  the app closes, allowing the launcher to be replaced. Update output is saved
  to `update.log` beside settings, and the next launch reports the real result.
  A nonzero exit is no longer described as a harmless success.

## Upgrading

Close all running Torrent Finder windows before upgrading from an older version,
then run this from a separate terminal:

```shell
pipx upgrade torrent-finder-cli
```

For a regular pip installation, use `python -m pip install --upgrade torrent-finder-cli`.
Standalone users can download the Windows, Linux, or macOS
asset from this release. Source checkouts can update with `git pull --ff-only`.

The credential migration can recover existing files in old locations; it cannot
restore files that were deleted or credentials previously supplied only through
environment variables. An existing stable credential file, including one emptied
by clearing credentials, remains authoritative.
