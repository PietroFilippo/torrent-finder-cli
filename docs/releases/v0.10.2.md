# Torrent Finder CLI v0.10.2

A search that finds nothing now says where else to look, and Manga › General
searches Madokami too once its login is saved.

## Changes

- **Advice when nothing is found.** The search notices (**n**) name the sources
  that were left out and how to add them:
  - Manga › General: **Nyaa (Raw)**, where Japanese raw scans often are (type
    `raw` after the title to include it for one search), and **Nyaa
    (Non-English)** (type the language, such as `português`).
  - Software › Mobile: **F-Droid**, for free and open-source apps.
  - Madokami, FitGirl and Online-Fix point to their category's General search,
    and RuTracker to Desktop, unless that provider was part of the same search.

  The advice appears only when the whole search found nothing.
- **Madokami in Manga › General.** With a Madokami login saved in Credentials,
  General Manga searches the Madokami library beside the public trackers, and
  its picks still download directly. Without a login it is left out quietly,
  not reported as a failure, and the advice says how to add it. Manga ›
  Madokami stays for a Madokami-only search. A search across both providers
  sends Madokami one request.

The report behind this: `naki no ryuu` found nothing in Manga › General. The
series is on Nyaa only as Japanese raws, and it is on Madokami.

## Limitations

- Raws are not searched automatically when nothing else is found, so a reader
  who asked for English never gets untranslated results unasked. Follow the
  advice, or set Nyaa (Raw) On under **F** (Filters & engines).
- Madokami becomes **On** in existing Manga › General settings. Set it **Off**
  under **F** to keep General to public trackers.

## Upgrading

Close running Torrent Finder windows, then use a separate terminal:

```shell
pipx upgrade torrent-finder-cli
```

For regular pip installs, use `python -m pip install --upgrade
torrent-finder-cli`. Standalone users can replace their executable with the
Windows, Linux or macOS asset. In-app updates from v0.10.0 and later work as usual.

**Full changelog:** https://github.com/PietroFilippo/torrent-finder-cli/compare/v0.10.1...v0.10.2
