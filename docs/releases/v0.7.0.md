# Torrent Finder CLI v0.7.0

Search across providers with saved profiles, keep releases for later, discover
works by alternate titles or topics, and send torrents directly to qBittorrent.
This release also makes search failures visible and improves navigation after
downloads.

## Search and discovery

- **Search across providers:** combine selected providers in one search while
  keeping their own engines and filters. Duplicate torrents merge without losing
  provider/source attribution or the correct download actions. Open partial
  results with **Enter**; combined searches stop waiting after 30 seconds.
- **Named search profiles:** save, switch, rename, and delete setups under
  **Search across providers → Ctrl+F → Profile**. A profile can select one or
  several providers. Use `torrent --profile "Anime + Manga" -q "Saki"` from the CLI.
- **Require or Prefer:** presets cycle **Off → Require → Prefer**. Prefer ranks
  matches without excluding other releases; Require remains strict. Save a
  default result order per provider or profile. Anime starts without a resolution
  requirement, so older 480p/720p releases remain eligible.
- **Explicit name and language controls:** apply All words, Any word, Exact
  phrase, and Exclude words rules. Choose Anime's Nyaa language category; Manga
  has separate English, non-English, and raw switches. Anime also has separate
  PT-BR audio-tag and subtitle-tag presets.
- **Search diagnostics:** press **n** in results to inspect each source's outcome,
  queries, counts, and filtering evidence. Missing/rejected logins, source errors,
  timeouts, empty responses, and filtered results are distinct. Press **r** to
  retry failed sources while keeping successful results and selections.
- **More results:** press **m** for deeper Nyaa and Knaben pages. Paging is bounded,
  preserves selections and sorting, and reports unsupported or exhausted sources.
- **Alternate titles:** **Quick actions → A** identifies a work, then lets you
  review up to six English, native, romanized, alternative, or manually entered
  names before searching. History retains the exact chosen queries.
- **Topic discovery:** **Quick actions → D** finds explicit catalog terms, then
  works matching the selected criteria. For example, Anime's `time travel`
  lookup offers **Time Manipulation** for review. Choose up to three works and
  review their release-search names before searching.

## Saved results and download clients

- **Bookmarks:** press **b** in results to save checked torrents or the focused
  row. **Tab → B** opens Bookmarks from the main menu, What's Next, or a search
  prompt. Reopen saved results, compare them, refresh their metadata, or replay
  saved searches. Bookmarks survive restarts.
- **Expanded details:** **i** opens listing metadata without the bright inverted
  background; **[** and **]** scroll the details. Filename hints remain separate
  from source metadata.
- **Settings transfer:** **Quick actions → E** exports portable settings and
  optionally history. Import previews Merge or Replace before applying. Bookmarks,
  statistics, and machine-specific settings stay local. Credential transfer is
  a separate, explicitly labelled plaintext export/import.
- **qBittorrent WebUI:** configure the optional connection under **Quick actions
  → Q** or **Credentials**. Single and batch menus can send magnets and supported
  torrent files after reviewing the client folder and category. Existing hashes
  are detected without changing their destination. View real client progress,
  speed, ETA, and state; **R** refreshes the snapshot.

## Navigation and updates

- Main and What's Next menus share **⚡ Quick actions**; provider-specific
  actions ask for a provider when opened from a general menu. Actions opened
  inside a provider retain that provider's scope.
- Download Method and batch flows offer **Continue to What's Next** or **Back
  to download options**. Back, **Esc**, or **Ctrl+C** retains the current torrent
  session or batch selection without repeating the completed action.
- What's Next shortcuts are **R** Search Again, **P** Change Provider, **M** Main
  menu, **Tab** Quick actions, **H** Search History, **S** Usage Stats, **T** Tips,
  **C** Credentials, and **Q** Exit. Letter shortcuts accept either case; exit
  still asks for confirmation. Compact menus and resizing preserve usable space.
- Package updates show activity, elapsed time, and the actual result. On Windows,
  a separate progress window follows the hidden installer while the main app
  closes, then reopens the app after a successful update. Failures stay visible.
  Try the non-installing preview with `torrent-finder --preview-update`.

## Scope and compatibility

- Topic/title catalogs are AniList for Anime/Manga, TMDB for Movies/Series,
  IGDB for Games, and Open Library for Books. TMDB and IGDB need their optional
  credentials. Topic discovery uses catalog vocabulary, not arbitrary semantic
  sentences; Software still uses literal searches. Catalog matches do not
  establish release availability or working multiplayer.
- Source language categories and filename tags cannot verify media tracks.
  Deeper retrieval is currently available for Nyaa and Knaben, not every source.
- qBittorrent WebUI must already be enabled and configured by the user. The app
  does not change its exposure or authentication settings. It sends full torrents;
  file selection is managed in qBittorrent. Direct downloads are skipped. A
  submission acknowledgement or 100% client progress is not verified completion.
- Existing combined settings become **Default**; enabled presets remain
  **Require**. Solo settings remain independent. Older versions cannot provide
  named-profile switching or preference ranking.

## Upgrading

Close running Torrent Finder windows, then use a separate terminal:

```shell
pipx upgrade torrent-finder-cli
```

For regular pip installs: `python -m pip install --upgrade torrent-finder-cli`.
Standalone users can replace their executable with the Windows, Linux, or macOS
asset from this release. Source checkouts can use `git pull --ff-only`.

The installed version controls the updater interface: upgrading from v0.6.0
uses its existing screen; subsequent updates use the new progress display.

Validation: **403 automated tests**, plus Windows terminal checks of navigation,
bookmarks, provider scoping, handoffs, and compact/resized layouts. Client
submission tests used an isolated WebUI fixture and intercepted desktop handoffs.
