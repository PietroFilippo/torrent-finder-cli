# Torrent Finder CLI v0.8.0

Find the work you asked for, under the name you know it by. Every provider now
ranks the requested title, film, book, program or app above sequels, look-alikes
and add-ons, and retries names it did not find. Downloads, streams and saved
settings are also much harder to lose or break.

## Better results in every provider

- **The requested work first.** Movies rank the film above its sequels and
  remakes (`Blade Runner` before `Blade Runner 2049`) and read translated
  `Матрица / The Matrix [...]` listings. Books rank the requested work and, when
  its author is reliably known, that author's editions first. Desktop and Mobile
  rank the program or app above longer products and add-ons (`Photoshop` before
  `Photoshop Lightroom`, `Minecraft` before `Mod for Minecraft`). Madokami lists
  the series named as searched, then its folders.
- **Other spellings, once.** When the sources answer but nothing matches:
  - a spelled-out number is searched in digits, in every provider
    (`Twenty First Century Boys` → `21st Century Boys`);
  - General Manga and Madokami search AniList's name for the work
    (`Yokohama Shopping Log` → `Yokohama Kaidashi Kikou`, `Attack on Titan` →
    `Shingeki no Kyojin`);
  - FitGirl tries the final number the other way (`Civilization VI` →
    `Civilization 6`).
  A notice names the extra search.
- **Typed tags after a title** apply to that search only: `Berserk português`
  (Manga languages and Raw), `Photoshop mac` / `… portable` (Desktop),
  `Minecraft obb` / `… apk` / `… mod` (Mobile), `Finding Nemo 1080p` (Movies).
  The title alone is searched too, tagged releases come first among equally
  good matches, and a notice says how many carry the tag.
- **Games:** FitGirl and Online-Fix search the title without words such as
  `fitgirl`, `repack` or `linux`; apostrophes no longer matter
  (`Baldurs Gate 3`). Both game providers share one FitGirl search. Online-Fix
  parses only real results, keeps its required 10-second spacing, and suggests
  one distinctive word when a multi-word title finds nothing.
- **Manga:** language presets (Portuguese, Spanish, French, Italian, Raw) search
  the matching Nyaa category even when it is Off.
- **Madokami:** results say what a pick opens (`[series folder]`, `[folder]`,
  `[file]`). Picking a folder opens it: step into release folders, see file
  sizes and pick volumes; **Esc** goes up a level.

## Faster and wider sources

- **Desktop** searches Knaben alongside APIBay. **Mobile** searches Knaben first,
  with APIBay as the Auto fallback. In the provider audit, APIBay averaged over
  5 seconds and found rows for 8 of 32 programs and 1 of 32 Android apps.
- **F-Droid (Mobile, Off by default):** free and open-source Android apps from
  the official repository, with the exact package shown (`VLC
  [org.videolan.vlc]`). A pick downloads the suggested APK from f-droid.org only.
- **Books:** Knaben also runs when the primary sources only found other books.
- **Knaben** uses its cacheable v2 API with the same results. **SolidTorrents**
  pauses for its Retry-After instead of being asked again.
- **RuTracker** tells Cloudflare's browser check apart from a wrong password and
  waits five minutes before trying again.
- **History** keeps 2,000 searches.

## Downloads, streaming and saved settings

- **Downloads never overwrite or escape the download folder.** Files arrive
  under their final name only when complete; a taken name becomes `Name (1).ext`;
  server-provided names are made safe. This now covers Madokami, Libgen,
  F-Droid, Online-Fix `.torrent` files and Jimaku subtitles.
- **Esc** leaves the wait before a download (Libgen link, F-Droid version,
  Online-Fix `.torrent`, Madokami folders, RuTracker/FitGirl magnets).
- **Streaming:** each stream owns its VLC window and closes it when it ends; a
  busy port 8080/8888 no longer sends VLC to another program; Ctrl+C stops
  downloads; `webtorrent`/`peerflix` no longer run through `cmd.exe`, which could
  break magnets at `&`; failures are explained with the stream's log.
- **Settings are saved within about a second** of a change, so closing the
  window no longer loses history or statistics. Two open windows no longer
  overwrite each other; an unreadable file is never overwritten, and a startup
  screen offers to retry or keep a copy and start fresh.
- **Fixed:** crashes when checking credentials with accented or `€` passwords
  or after typing `[` or `]` in a search; Ctrl+D in a text field no longer
  closes the app; an unusable download folder now offers another one instead of
  failing.

## Scope and compatibility

- RuTracker currently blocks scripted logins with Cloudflare's browser check, so
  its searches report "blocked". The app does not try to get around the check.
- F-Droid has no commercial games or apps. Android checks the APK's signature on
  install; F-Droid's PGP signature is linked but not checked by the app. Apps
  published per CPU type download F-Droid's suggested build, and the done panel
  says so.
- Retries under other names use AniList only when it lists what you typed as a
  title or synonym. Spelling retries run once and only when nothing matched.
- The Manga → Magazine search depends on Jikan, whose API was unavailable when
  this release was prepared.

## Upgrading

Close running Torrent Finder windows, then use a separate terminal:

```shell
pipx upgrade torrent-finder-cli
```

For regular pip installs: `python -m pip install --upgrade torrent-finder-cli`.
Standalone users can replace their executable with the Windows, Linux, or macOS
asset from this release. Source checkouts can use `git pull --ff-only`.

Saved settings carry over. Engine choices you saved are kept, so if Desktop or
Mobile still shows Knaben **Auto**, set it to **On** under **Filters & engines**
(Ctrl+F) to get the faster search. Going back to an older version keeps working,
but it trims history to its own limit of 50 searches.

Validation: **646 automated tests** on Windows and Linux, including tests that reintroduce each fixed
defect, replays of the October 2026 provider audit's real listings, and live
searches on the changed sources. A final review by GPT-6.1-Sol and four Claude
reviewers found about 56 issues; all confirmed ones are fixed here.
