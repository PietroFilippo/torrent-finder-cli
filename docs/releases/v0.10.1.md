# Torrent Finder CLI v0.10.1

Knaben now searches alongside the other engines from the start.

## Changes

- **Knaben is On by default** for Movies & Series, Games, Anime, Manga and
  Books, as it already was for Desktop and Mobile. Every search makes one
  category-scoped Knaben request beside the other On engines, instead of only
  when they came back empty. Set it to **Auto** or **Off** under **F** (Filters
  & engines) if you prefer the old behaviour.
- Saved choices record every engine's mode, so a Knaben **Auto** saved for
  those five by an earlier version, almost always the old default, turns **On**
  once on the first start. An Auto you choose from now on is kept, and saved search
  profiles keep the modes they were saved with.

## Upgrading

Close running Torrent Finder windows, then use a separate terminal:

```shell
pipx upgrade torrent-finder-cli
```

For regular pip installs, use `python -m pip install --upgrade
torrent-finder-cli`. Standalone users can replace their executable with the
Windows, Linux or macOS asset. In-app updates from v0.10.0 work as usual.

**Full changelog:** https://github.com/PietroFilippo/torrent-finder-cli/compare/v0.10.0...v0.10.1
