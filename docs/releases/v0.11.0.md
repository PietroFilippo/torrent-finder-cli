# Torrent Finder CLI v0.11.0

The Athanor paintings lose their frames, ten wide paintings fill the window,
the Windows Terminal profile gets an icon, and the advice for a search that
finds nothing now actually shows.

## Paintings

- **No more boxes.** Every painting is cropped to the picture: printed
  margins, captions and borders are gone. The edges facing the text dissolve
  into the page dot by dot, in the engraving's own grain, so a painting
  belongs to the page instead of sitting on it. The fade follows the side you
  choose.
- **Twenty paintings.** The ten plates are joined by ten **wide paintings**
  that fill the whole window behind the text: Rembrandt's *The Three Trees*,
  Friedrich's *The Abbey in the Oakwood* and *The Sea of Ice*, five mezzotints
  by John Martin (*Satan presiding at the Infernal Council*, *The Deluge*,
  *The Fall of Nineveh*, *Pandemonium*, *The Opening of the Seventh Seal*),
  Doré's *Over London by Rail* and Böcklin's *Isle of the Dead*. All are
  public domain or CC0 on Wikimedia Commons; the credits are in
  `torrent_finder/assets/paintings/CREDITS.md`.
- **Their own look.** Each painting is drawn with the dot pattern that suits
  it: fine engraving lines, film-like grain, or a line screen (*The
  windmills*). *The Hermit* now glows as an outline figure, its lantern kept.
- **Stronger ink.** The colourways' painting ink is about twice as present.
  A plate on the left, or a wide painting, sits under the text in a fainter
  ink, so the text keeps its contrast.
- **Organised.** Settings › Appearance lists **None**, the plates, then
  **Wide paintings** from the oldest. A wide painting always fills the window,
  so it has no side to choose; **Painting image** saves the picture as a PNG.

## Windows Terminal profile

- The profile's tab shows a **lantern** icon in the colourway's colours.
- **After updating**, an installed profile is redrawn once when the app
  starts, from your saved choices, so the new paintings and the icon appear
  without a visit to Settings. If the saved settings cannot be read, the
  profile is left alone until they can.

## Searching

- **The advice for an empty search now shows.** v0.10.2 added it, but the
  results screen dropped it. The notices (sources left out and how to add
  them, failures, titles that found nothing) appear above the results and
  first in diagnostics (**n**), for every kind of search, and stay current
  after **r** retry and **m** more. In short windows their count rides on the
  diagnostics line, so the keys stay on screen; Enter opens a notice's whole
  text.
- A **seed minimum** no longer removes direct downloads and site listings
  without a swarm: Madokami in Manga › General, FitGirl and Online-Fix in
  Games › General.
- Typing a language after a title (`Berserk portuguese`) no longer ranks the
  series' Madokami folder below its spin-offs.
- In a search across providers, a Madokami folder both manga providers find
  is listed under Manga › Madokami.
- Madokami results are no longer reused for 30 seconds after you change your
  login.

## Streaming

- **peerflix** now serves streams and downloads to this computer only; it
  used to listen on your whole network. **webtorrent** has no such option:
  its server still listens on every network the computer is on, so on a
  shared network prefer peerflix.

## Upgrading

Close running Torrent Finder windows, then use a separate terminal:

```shell
pipx upgrade torrent-finder-cli
```

If pipx still reports the old version right after the release, ask for this
one: `pipx install --force "torrent-finder-cli==0.11.0"`. For regular pip
installs, use `python -m pip install --upgrade torrent-finder-cli`.
Standalone users can replace their executable with the Windows, Linux or
macOS asset. In-app updates from v0.10.0 and later work as usual.
