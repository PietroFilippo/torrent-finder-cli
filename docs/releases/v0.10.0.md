# Torrent Finder CLI v0.10.0

Search and downloads can keep moving at the same time. This release adds
optional background aria2c downloads, an English or Brazilian Portuguese
interface, and another round of work on the terminal layout, history and
batch actions.

## Highlights

- **Background downloads:** turn on **Downloads run: in background** in a
  torrent's download menu. aria2c then downloads single torrents or batches
  while you search. **D** opens Downloads from the main menu or What's Next;
  **G** opens it from quick actions. The screen follows progress, stops a job,
  resumes a stopped one in its own folder, retries a failed one and opens its
  folder. The status line (Simple: a header badge) follows active work on
  menus, the results table and the search prompt, and every way of quitting
  asks first while downloads run.
- **Two interface languages:** **Settings › Language** chooses Automatic,
  English or Português (Brasil). `--lang CODE` and `TORRENT_FINDER_LANG` choose
  a language for a run or shell. Menus, prompts, `--help` and argument errors
  are translated; the keys stay the same.
- **History and batch recovery:** **/** finds history entries by text, **X**
  removes one and **U** restores the last one removed. **Enter** replays with
  the filters recorded then; **C** uses current filters. After a partial
  **Open all in your client** handoff, retry only failed or unattempted items.

## Interface and appearance

- In tall windows, help follows the list while the key bar stays at the
  bottom. Section headings stay with their first row. Windows smaller than
  30×8 show one **Enlarge the window** line until resized.
- Simple has a notice line above its keys. The download menu names where
  **Back to results** and **Done with this torrent** lead.
- Athanor's **Painting side** offers Right, Left or Both sides; Both sides
  adds a faded companion engraving. Windows Terminal profile fonts, text
  sizes and the Athanor plain look can be chosen per design.
- Torrent information wraps to terminal cells, including wide characters.
- In menus and results, **?** lists every key at any window width. **Space**
  in Appearance previews colours only; other rows apply with **Enter**.
- In-app updates run in the app's own window: the update screen shows each
  stage and the download progress, then reopens the app. Updating from v0.9.0
  to this version still uses v0.9.0's updater; the new one applies from then on.

## Downloads, search and data

- Background jobs share a hidden aria2c engine with up to two active
  downloads. Downloads reports completion and failure; stopped downloads keep
  their partial files. In-app updates wait until active work finishes or is
  stopped.
- Search results redraw when they change, reducing idle CPU use. Results also
  keep focus and typed titles through shortcuts, restore the workspace after
  download options, and continue **Load More** past rejected pages.
- A source checkout reports its version from Git tags. Session runtime now
  adds up across saved sessions. Settings exports include portable appearance
  and language choices and the background download setting.
- A search for several titles still saves each one to history, but the usage
  stats count only the titles that found something.
- The README is shorter; the [user guide](../guide.md) holds the full feature
  and key reference, and [development](../development.md) holds contributor
  workflows.

## Fixes

- Windows key input keeps a typed **à** in searches and forms; other accented
  text is preserved too.
- Credential migration preserves keys another window saved. An unreadable
  credential file is left intact.
- Archive extraction leaves an archive packed when page names collide.
- Timed-out update installers stop with their child processes.
- A peerflix download finishes once every piece is present. Several small UI
  fixes cover update checks, navigation, notices and compact screens.
- On Python 3.10, Ctrl+C stops a download in the terminal at once. Release
  builds now run the tests on Python 3.10 as well as the newest Python.

## Known limitations

- Background mode covers aria2c downloads only. webtorrent, peerflix, direct
  downloads and streaming stay in the foreground. Background jobs belong to
  this app session and stop when it exits; they do not survive a restart.
- A language preset reads explicit release names and tags, not the audio or
  subtitle tracks inside a torrent. Searches send the words you type.
- Paintings need terminal background-image support. The Windows Terminal
  profile shows them in version 1.24 or later; other terminals can use the
  exported image. The inspector pane needs at least 150 columns.

## Upgrading

Close running Torrent Finder windows, then use a separate terminal:

```shell
pipx upgrade torrent-finder-cli
```

For regular pip installs, use `python -m pip install --upgrade
torrent-finder-cli`. Standalone users can replace their executable with the
Windows, Linux or macOS asset. Source checkouts can use `git pull --ff-only`.

Nothing needs migrating. Existing settings carry over. Background downloads
are off by default, so aria2c stays in its current screen until you turn the
setting on. Language defaults to Automatic and follows the system's display
language; saved appearance and filters keep their choices.
