# Torrent Finder CLI v0.12.0

Every screen is redesigned around what you are doing: menus keep their keys
with them instead of across an empty window, direct downloads run in the
background, and the paintings are sharper and easier to read text over.

## A calmer layout

- **No more dead space.** A menu, the focused row's help, the rule and the
  keys now stay together from the top of the window; the rest is left to the
  painting. A nine-row menu such as What's Next no longer sits above forty
  empty rows with its keys at the bottom. Long lists still fill the window.
- **The inspector fits a laptop window.** The pane with the focused row's
  details now shows from 120 columns, right beside the list, instead of from
  150 columns at the far side. It is not drawn when it would only repeat the
  row's name, and its divider ends with its lines.
- **Keys you can trust.** The key bar no longer moves as you move between
  rows; **? keys** always has a place in it; and keys appear only where they
  do something (no "Space select" on an empty table, no "X stop" on a finished
  download). Lists of shortcut letters left the key bars: each row shows its
  own letter.
- **Small windows** show at least three choices, two rows of keys and a
  one-line announcement; the frame's title drops the app's name before the
  screen's.
- **Confirmations** are a compact question whose key says what it does:
  `Y quit`, `Y delete`, `Y stop all`.

## Screens

- **What's Next**: one **Choose provider** row (**P**; **M** still works)
  replaces "Change provider" and "Main menu", which did the same. Every row
  explains itself, and **Search again** shows the provider you just searched:
  its engines, filters and recent searches.
- **Main menu**: the room keeps its name and one line; the "Obvious exits"
  line, which listed the rows below it, is gone.
- **Results**: the name column takes only the width the names need, so size
  and seeds stay next to them in a wide window. An empty table says whether
  the search found nothing or your refinement hides every result.
- **Refine results** groups **Name matching** and **Order**.
- **Tips** are listed by their first words, with the whole tip beside or under
  the list; **Enter** reads one on its own page. Rotating tips are short
  enough for two lines.
- **History** keys read **Enter run again** and **C run with current
  filters**.

## Downloads

- **Direct downloads run in the background too**, and background downloads
  are now **on by default**: Madokami, Libgen and F-Droid files queue as jobs
  beside aria2c torrents, two at a time, and the Downloads screen follows them.
  The switch is in a torrent's download options and on the Download Folder
  screen; an empty Downloads screen offers it too.
- **A** on the Downloads screen **stops all** downloads, after saying what
  stopping loses.
- A failed download says **why in plain words** ("No peers answered for a
  long time.") and what Enter offers; the engine's lines stay in the details,
  without the magnet link. Unpacked folders are summed up.
- The status line reads **↓ 2 running · 1 queued · 3.1 MB/s**; a percentage
  shows only for a single download. The **T** counter left the status line.

## Paintings and colour

- **Sharper paintings**: drawn from larger scans at about a window's height,
  one dot per pixel, so the engraving's detail shows and the texture behind
  the text is finer. A plate on the right is drawn a little fainter (85%), so
  text beside it stands out.
- **Both sides** is chosen in the one painting list: **Enter** puts a plate on
  the right, **L** on the left. The separate Left painting section is gone.
  The grain paintings read as film rather than noise.
- **Text over the painting** is now measured on the paintings themselves:
  muted, error, warning and accent text are a little lighter in the Athanor
  colourways, so every kind of text stays readable where it crosses the
  picture, and muted text still reads as secondary.
- An installed Windows Terminal profile is redrawn once at start with the new
  pictures.

## Upgrading

Close running Torrent Finder windows, then use a separate terminal:

```shell
pipx upgrade torrent-finder-cli
```

If pipx still reports the old version right after the release, ask for this
one: `pipx install --force "torrent-finder-cli==0.12.0"`. For regular pip
installs, use `python -m pip install --upgrade torrent-finder-cli`.
Standalone users can replace their executable with the Windows, Linux or
macOS asset. In-app updates from v0.10.0 and later work as usual.

Background downloads are now on by default. To watch each download in its own
screen as before, choose **Downloads run: in this screen** in a torrent's
download options or under Settings › Download folder.
