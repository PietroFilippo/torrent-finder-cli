# Torrent Finder CLI v0.9.0

A new look. Every screen follows one quiet layout, the app comes in two
designs with eleven colour themes, and the new default, **Athanor**, frames the
terminal like a roguelike scriptorium, with a public-domain engraving behind it
in Windows Terminal.

## Two designs

- **Athanor** (the default) draws every screen in a double-line frame. Its top
  edge names the screen and what it is about (`torrent-finder » Movies &
  Series › dune`), a message line above it says what just happened, and a
  NetHack-style status line below counts your searches, picks and bookmarks
  beside the date, the VPN check and the version. Five colourways, named for
  the stages of the alchemical work: **Citrinitas** (lamplight amber),
  **Rubedo**, **Albedo**, **Viriditas** and **Nigredo**.
- **Simple** is the quiet look without a frame: one header line, thin rules,
  one key bar. Six themes: **Quiet Blue**, **Iris**, **Lagoon**, **Ember**,
  **Mono** and **Paper** (for light terminals).
- **Settings › Appearance** previews a design or colours on the whole screen
  with `Space` and saves with `Enter`. It also sets the focus style (a cursor
  bar or a tinted row) and the density (**Compact** fits more rows). `--theme
  NAME` or `TORRENT_FINDER_THEME=NAME` choose one for a run without saving it.

## Paintings, and a Windows Terminal profile

- Athanor has a **painting**, chosen apart from the colours, which recolour it:
  ten public-domain engravings, six by Gustave Doré (Satan in profile, Satan's
  despair, the windmills, the Raven, Charon, the Ancient Mariner's ice) plus
  Dürer's *Melencolia I*, the Flammarion engraving, Pamela Colman Smith's
  *Hermit* and an emblem from Maier's *Atalanta Fugiens*.
- A terminal app cannot draw behind its own text, so on Windows **Add a
  torrent-finder profile** (Settings › Appearance) gives Windows Terminal a
  profile that opens the app on the theme's own page, with the painting behind
  the text and the IBM VGA 8x16 pixel font. It follows later colour and painting
  choices; restart Windows Terminal, then open **torrent-finder** from the ▾
  menu next to the tabs.
- Anywhere else, **Save the painting as an image** writes a PNG in your colours
  to `Pictures/torrent-finder` for your terminal's background setting.

## Every screen, reworked

- **Main menu:** sections for CONTINUE (reopens your newest search), SEARCH and
  TOOLS; each provider says which engines and presets it will use; the header
  shows the version, a pending update and the network check.
- **Wide windows:** from 150 columns an **inspector** on the right describes
  the focused row: a provider's engines with On/Auto/Off, its presets, your
  recent searches there and its counts; Continue's earlier searches; which
  logins are set; the download folder's free space; the appearance in use.
- **Search screen:** engine and preset states in their colours, and a RECENT
  list of past searches that filters as you type.
- **Search progress:** a line per provider with each engine's state (a row
  count, timed out, blocked…).
- **Results:** the focused row explains itself with release tags and, under
  Recommended order, why it ranks there.
- **Download menu:** a summary of the picked torrent and the recommended way
  marked.
- **Stats** compare counts with bars; **search diagnostics** come in sections
  with each state beside its evidence; `?` on any menu lists its keys; tips sit
  at the bottom of the screen when there is room.
- **Network warning:** the public IP and location stay masked until `R`.
- **Smoother drawing:** frames overwrite the previous one instead of clearing
  the screen, so large windows no longer flicker.

## Fixes

- Paths, names, queries and error text containing `[brackets]` display as
  written everywhere instead of being read as styling.
- Cancelled downloads never publish a partial file, cancelled fetches say so,
  and an Online-Fix batch stops on `Esc`.
- The "press Esc again to quit" hint clears once you choose anything else.
- Sign-in forms, the network warning, confirmations and results fit small
  windows with their keys visible.
- Upload dates far in the future no longer crash result details on Windows.
- Rendering the status line no longer slows down with many bookmarks.

## Limits

- The painting needs a background picture from the terminal: the Windows
  Terminal profile shows it from Windows Terminal 1.24 (older versions get the
  colours and font only), and other terminals need the saved image.
- Outside that profile, themes colour the text and the page stays the
  terminal's own: set your terminal to a light scheme before choosing Paper.
- The VGA font has no bold, so the profile draws bold text at normal weight.
- With Python from the Microsoft Store, the app writes the profile from outside
  the Store's private copy of AppData so Windows Terminal can find it.
- The inspector needs a window at least 150 columns wide; in very small windows
  (about 20x8) the results table crops its last keys.

## Upgrading

Close running Torrent Finder windows, then use a separate terminal:

```shell
pipx upgrade torrent-finder-cli
```

For regular pip installs: `python -m pip install --upgrade torrent-finder-cli`.
Standalone users can replace their executable with the Windows, Linux, or macOS
asset from this release. Source checkouts can use `git pull --ff-only`.

Saved settings carry over. The first start shows the new Athanor design; to
keep the earlier look, choose **Settings › Appearance › Simple** (Quiet Blue).

Validation: **905 automated tests** under both unittest and pytest, every
screen captured at five sizes from 40x12 to 200x50 in all eleven themes with no
overflow, a run of the real app in a pseudo-terminal, and two rounds of
independent code review, with the issues they found fixed and tested.
